\# Micromouse Project



This is a C-based Micromouse simulation and control system 



\## Features

\- Maze representation and solving logic

\- Floodfill / path planning algorithm

\- Robot controller logic

\- Sensor simulation (IR-based)

\- Physics simulation environment



\## Architecture

\- `src/` → Core implementation (C code)

\- `include/` → Header files / APIs

\- `CMakeLists.txt` → Build system



\## Build Instructions



```bash

mkdir build

cd build

cmake ..

make
